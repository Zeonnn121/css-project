# Objectives

After completing the XSS Virtual Lab, the learner should be able to:

1. Define Cross-Site Scripting and distinguish reflected, stored, and
   DOM-based XSS.
2. Explain how untrusted input can become executable browser content.
3. Trace data from an input field through the server and into the rendered
   page.
4. Demonstrate the difference between vulnerable and secure rendering in the
   isolated lab.
5. Explain why output encoding, safe DOM APIs, input validation, and Content
   Security Policy provide protection against XSS.
6. Compare the vulnerable and secure implementations used by the lab.
7. Interpret activity logs and simulation results.
8. Complete the assessment with a minimum target score of 70%.
