# References

The following resources provide authoritative background and practical
guidance for the topics covered by this lab:

- [OWASP Cross Site Scripting](https://owasp.org/www-community/attacks/xss/)
  - XSS concepts, examples, and risk.
- [OWASP Cross Site Scripting Prevention Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Cross_Site_Scripting_Prevention_Cheat_Sheet.html)
  - Context-aware output encoding and prevention practices.
- [OWASP Top 10](https://owasp.org/Top10/)
  - Application security risks, including injection.
- [MDN: Cross-site scripting (XSS)](https://developer.mozilla.org/en-US/docs/Glossary/Cross-site_scripting_XSS)
  - Browser and web-platform terminology.
- [MDN Web Security](https://developer.mozilla.org/en-US/docs/Web/Security)
  - Browser security concepts and defensive APIs.
- [MDN: Content Security Policy](https://developer.mozilla.org/en-US/docs/Web/HTTP/CSP)
  - CSP directives and deployment guidance.
- [PortSwigger Web Security Academy: XSS](https://portswigger.net/web-security/cross-site-scripting)
  - Additional controlled, educational XSS labs.

The application also exposes these references through its References page.
Use the local lab documentation and application controls before attempting any
practical exercise.
